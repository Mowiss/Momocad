Guide & Raccourcis

🖱️ Souris & Navigation

  • Clic Molette (Maintenu) : Se déplacer sur le plan (Panoramique).
  • Molette (Roulette) : Zoomer / Dézoomer.
  • Maj (Shift) + Tracé : Forcer un trait horizontal ou vertical.
  • Clic + Maj (Shift) : Ajouter/Retirer un élément de la sélection.

⌨️ Raccourcis Clavier

  • Saisie + Entrée : Indiquer la distance, l'angle ou la valeur d'un décalage.
  • Échap (Esc) : Revenir à l'outil Sélection.
  • Suppr / Retour arrière : Supprimer les objets sélectionnés.
  • Ctrl + Z / Ctrl + Y : Annuler ou Rétablir une action.
  • Ctrl + C / Ctrl + V / Ctrl + X : Copier, Coller ou Couper.

🛠️ Outils Spéciaux

  • Ajuster (Trim) : Cliquez sur la portion de ligne à supprimer.
  • Prolonger (Extend) : Cliquez près de l'extrémité d'une ligne.
  • Décaler (Offset) : Tapez la distance désirée, puis cliquez sur l'objet.
  • Cotation angulaire : Clic 1 = sélectionner D1, Clic 2 = sélectionner D2, Clic 3 = poser l'arc de cote. Sélection de la cote en cliquant sur la valeur °.
  • Impression PDF : ESPACE pour pivoter, MOLETTE pour l'échelle, CLIC pour générer le PDF.
